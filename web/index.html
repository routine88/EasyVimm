Skip the A–Z scan next time

By default EasyVimm opens Vimm's A–Z list so you can find each game. If you capture the exact vault IDs once, the app will jump straight to each game's page after that — no searching.

  1. Drag this link to your browser's bookmarks bar: EasyVimm: Grab IDs
  2. Open a Vimm vault list — e.g. vimm.net/vault/NES. Solve any Cloudflare check.
  3. Click the bookmark. It copies JSON of every title → vault-ID pair on that page to your clipboard.
  4. Paste the JSON below and click Save IDs. Repeat once per console.
